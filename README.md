# ash-cli

A lightweight Linux system information CLI written in Python.

`ash-cli` is a personal open-source project built to explore Linux system information, Python CLI development, system administration, and software engineering practices.

The project is being developed on Ubuntu Linux and is designed to eventually provide a simple command-line interface for monitoring and inspecting a Linux system.

---

## 🚧 Project Status

**Early development**

Currently implemented:

- System information
- CPU information
- Memory information
- Swap usage
- Disk usage
- System uptime
- Command-line argument parsing

Planned features include:

- System health monitoring
- Systemd service inspection
- JSON output
- Better error handling
- Automated testing
- Python package structure
- Installation through `pip`
- Linux package support
